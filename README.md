# KasiTix
Building the backend for KasiTix, a ticketing API for community events : a jazz night at a Soweto hall,
a Saturday market in Khayelitsha, a school fundraiser in Mamelodi

## About
Organiser creates an event and adds ticket types to it, such as General R80 or VIP R250, each witha fixed capacity.
Publishing the event opens it for sale. Buyers place orders, and one order can include several ticket types. 
Every ticket type has a limited number of seats and two people buying the last seat at the same time/moment,both wouldnever get it.
